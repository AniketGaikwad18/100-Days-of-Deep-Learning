Day 26 of my #100DaysOfDeepLearning journey.

I experimented with tuning:

Optimizers — Adam, SGD, RMSprop
Number of neurons
Number of hidden layers
Activation functions
Using RandomSearch to find better combinations

Instead of manually guessing hyperparameters, I learned how tuning can systematically search for a better-performing model.
