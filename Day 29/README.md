Day 29 — Pooling in CNNs 🧠📉

Continuing my #100DaysOfDeepLearning journey, today I focused on Pooling, an important operation in Convolutional Neural Networks (CNNs) used for downsampling feature maps while retaining important information.

📚 What I learned:
What Pooling is and why it is used in CNNs
Max Pooling — selects the maximum value from each region
Average Pooling — calculates the average value of each region
Global Average Pooling (GAP) — reduces an entire feature map to a single value
How pooling reduces spatial dimensions and computational cost
How pooling can help with translation invariance and generalization
Advantages and limitations of pooling, especially the possibility of losing fine-grained spatial information

I also worked through numerical examples using 2×2 pooling with stride = 2 to understand exactly how the feature maps are transformed.

One key takeaway for me today: convolution extracts features, while pooling helps summarize and reduce those features without keeping every spatial detail. 🚀
