Day 27 — Convolutional Neural Networks (CNNs) 🧠📸

Continuing my #100DaysOfDeepLearning journey, today I started learning the fundamentals of Convolutional Neural Networks (CNNs).

I covered:

What CNNs are and why they are useful for image and grid-like data
Basic CNN architecture — Convolution, Pooling and Fully Connected layers
How convolution filters/kernels extract features from images
Edge detection using convolution
Padding and why it helps preserve spatial information
Valid and Same padding
Stride and how it controls the movement of the filter and output size
The CNN output-size formula:
n′ = (n + 2p − f + 1) / s

The most interesting part was understanding how a CNN gradually learns features — starting from simpler patterns like edges and building towards more meaningful features through deeper layers.

Learning the concepts first, then implementing them — one day at a time. 🚀
