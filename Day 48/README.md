Day 48 — Self-Attention 🧠🔍

Day 48 of my #100DaysOfDeepLearning journey.

Today I focused on one of the most important concepts behind Transformers: Self-Attention.

I learned how self-attention allows each token to look at other tokens in the same sequence and determine which ones are important for understanding its context.

What I covered:
Static vs Contextual Embeddings
Why the same word can have different meanings depending on its context
How self-attention creates contextual embeddings
How each token considers the other tokens in the sequence
The basic flow:
Input Tokens → Self-Attention → Contextual Embeddings
Understanding context through examples such as the word “bank” in different sentences

The key idea I took away is that instead of giving a word one fixed representation, self-attention allows its representation to be influenced by the surrounding context. This contextualization is a core part of Transformer models.
