Day 8: Least Square Regression Line

🧠 Day 55 — Least Squares Linear Regression
Continuing my 100 Days of Deep Learning journey, today I practiced Linear Regression using the Least Squares Method by solving a HackerRank statistics challenge.
The challenge involved predicting a student's Statistics grade (Y) from their Math aptitude score (X) using five given data points. HackerRank asks us to determine the best-fit regression line and predict the expected grade when X = 80. HackerRank
🔹 What I Worked On
- Understanding the Least Squares Regression Line
- Calculating the slope (m) of the regression line
- Calculating the intercept (c)
- Forming the equation:
  ŷ = mx + c
- Using the regression equation to make a prediction
- Implementing the complete calculation in Python without relying on a machine-learning library
For the given dataset, the regression line is approximately:
ŷ = 0.6438x + 26.8493
Therefore, when x = 80:
ŷ ≈ 78.36
💻 Implementation
I implemented the calculations using the mathematical formula for the slope and intercept, then used the resulting model to make the prediction.
This was a good exercise in understanding what happens behind the scenes of Linear Regression, rather than simply using LinearRegression() from Scikit-learn.
💡 Key Takeaway
Today I connected the mathematical foundation of statistics and machine learning with actual implementation.
Data → Least Squares → Best-Fit Line → Prediction
The goal is not just to use ML libraries, but to understand the mathematics that makes the model work.
